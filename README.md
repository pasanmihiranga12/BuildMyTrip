# BuildMyTrip

BuildMyTrip is a customizable tourism package platform that allows users to explore destinations, create personalized travel packages, and manage bookings efficiently. The system supports both tourists and administrators with separate functionalities for smooth travel planning and management.

---

## 🚀 Features

### 👤 User Management
- Tourist registration and login
- Admin login system
- User profile management

### 🗺️ Destination Management
- Add, view, update, and delete destinations
- Destination details: name, location, description, image, and price

### 🎒 Package Customization
- Select destinations
- Choose hotel types
- Choose transport options
- Select activities
- Set number of days and travelers

### 💰 Cost Calculation
- Automatic package cost calculation
- Apply discounts and promotions
- Display final bill summary

### 📅 Booking Management
- Confirm bookings
- View booking history
- Cancel bookings

### 🛠️ Admin Panel
- Manage destinations
- Manage packages
- Manage users
- View all bookings

### 📊 Report Generation
- Booking reports
- Popular destination reports
- Revenue reports

---

## 🧑‍💻 Tech Stack

- Frontend: HTML, CSS, JavaScript / React
- Backend: Node.js / Express
- Database: MySQL / MongoDB
- Version Control: Git & GitHub
